## Goal

Go deeper on SailPoint than day-to-day administration: configure sources and identity profiles, design roles and access profiles, build access request and certification campaigns, and document the engineering decisions behind each.

## Plan

- Connect authoritative and target sources and build identity profiles from HR attributes
- Design a role model (birthright and requestable access)
- Set up access requests with approvals, and a certification campaign
- Write up each step as lab notes, the same way as the midPoint lab

This project is just getting started. Lab write-ups will be linked here as they're published.
